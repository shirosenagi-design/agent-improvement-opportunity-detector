PROJECT 04 — V5 PERSONALIZATION OPPORTUNITY MINING
===================================================

PURPOSE LOCK
Macro baseline -> Individual user model -> Personalized reasoning -> Opportunity mining -> Developer judgment

A = macro population baseline.
B = same base agent reasoning through a provisional model of this one user.
PROJECT 04 does NOT ask which answer is better. It asks what became visible at the individual scale that the macro baseline did not surface.

V5 removes response length, sentence count, concision, readability, and generic cognitive-load from quality judgment. Raw answers are preserved before analysis.
MBTI is only a hackathon cold-start bootstrap. It is not the research target.

FAST UPGRADE FROM V4
1. Close RUN_WINDOWS.cmd.
2. Extract project04_v5_opportunity_mining_PATCH_ONLY.zip into the current V4 folder.
3. Replace matching files.
4. SETUP_WINDOWS.cmd is NOT needed again.
5. Start RUN_WINDOWS.cmd and Ctrl+F5.
6. Run ONE live trial and verify the Agent Trace + Opportunity Mining section.

No API key is included. No live API/model call was made during this build. Codex was not used.
